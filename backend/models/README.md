# Models Directory
This directory will contain Mongoose Schemas for MongoDB Atlas:
- User.js (User credentials, profile, authentication)
- Will.js (Digital will document, beneficiaries, asset allocations)
- Letter.js (Future letters, scheduled delivery date, recipient email)
- VaultItem.js (Encrypted secret notes, credentials, memory assets)
- PersonalitySnapshot.js (AI extracted personality traits, voice, memories)
